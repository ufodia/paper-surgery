# Security policy

The current 0.1 development line receives security fixes. This local tool does not provide a security certification or a guarantee that user inputs are correct.

Report a vulnerability using [GitHub private vulnerability reporting](https://github.com/ufodia/paper-surgery/security/advisories/new). If the repository does not yet offer that form, use the profile contact route at [Ufodia](https://github.com/ufodia) to request a private channel. Do not put credentials, private files, or exploit details in a public issue.

Include the affected commit, a minimal synthetic reproduction, impact, and browser/OS details. There is no promised response SLA or bounty. For privacy boundaries and exported data, see [Privacy](docs/PRIVACY.md).
